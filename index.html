🔧 트러블슈팅 1 : 전(全) 구간 바코드 불일치 감지 및 오입출고 방지 인터록

문제: 아두이노·시리얼 모듈(QJ71C24N)을 통해 스캔한 데이터(D732)와 입출고 목표 번호(D140)가 불일치할 때 기존 시스템이 에러 처리 없이 모호하게 정지하여 큐 멈춤 및 오입고·오출고 위험 발생

해결: 전 번호 구간에서 데이터 불일치(<>) 감지 즉시 황색 경고등(Y16) 점등과 함께 크레인 서보 기동을 강제 차단(Interlock)하고, 현장 작업자가 확인 후 수동 리셋 버튼(M402 / M800)을 입력할 때만 에러가 해제되도록 예외 처리 프로세스 구축

🔧 트러블슈팅 2 : XY 2축 직선보간 및 M코드(M10~M70)·센서 완료 인터록

문제: 서보 위치결정(ZP.PSTRT1) 이동 중이거나 공압 포크(로드리스·듀얼로드 실린더)가 완전히 전·후진하지 않은 상태에서 후속 축 이동이 실행될 경우 팔레트 및 기계적 충돌 위험 존재

해결: 축 BUSY(X4C) OFF 및 원점복귀 완료(M30) 조건에서만 기동을 허가하고, 각 스텝의 M코드(M10·20·30·40·60·70) 출력 시 실린더 끝단 오토스위치(CS1~CS4, X00~X03) 검출 신호가 확인된 후에만 M코드 OFF 완료 신호를 인가하여 다음 서보 이동이 수행되도록 시퀀스 동기화

🔧 트러블슈팅 3 : 공압 이상 및 강제 에러 주입(D20·D22) 설비 보호·패트라이트 제어

문제: 필수 공압이 정상 범위를 이탈하거나 서보 축 에러(104·105)·통신 에러(X2E) 발생 시 즉각적인 시각·청각 경보와 설비 정지 검증 체계 필요

해결: 공압 비정상 및 HMI 테스트 에러 값(D20·D22) 강제 주입 시 즉시 동작 차단(Interlock)과 함께 적색 경보등(Y15) 점멸·부저를 출력하고, 정상 복귀 시 녹색등(Y17, M901 OFF) 점등 및 시퀀스 자동 재개 프로세스 구현

🔧 트러블슈팅 1 : Q64AD 전류·전압 하드웨어 매칭 및 센서 단선(AD < -50) 감지 · CT 감도 개선

문제: 4~20mA 전류 센서(온도·압력·전류)와 1~5V 전압 센서(유속 FM-215-8-P) 혼용 시 입력 임피던스 차이, 배선 단선 시 음수 AD값 유입, 소전류 부하에서 CT 센서 감도 부족 현상 발생

해결: Q64AD 전류 채널(CH1·2·4)은 내부 저항 쇼트바를 연결하고 전압 채널(CH3)은 쇼트바를 제거하여 신호를 매칭함. CT에 전선을 같은 방향으로 2회 관통시켜 측정 감도를 2배(20A→10A 범위)로 높이고, 공통 함수 블록(AD_Conv) 내에 현재값_AI < K-50 비교 로직을 넣어 단선 시 즉시 센서고장(M11·13·15·17) 경보가 점등되도록 구현

🔧 트러블슈팅 2 : 이기종 장비(MELSEC·Siemens) 다중 SMPS 공통 GND 구축 및 단위 배율 통일

문제: 터빈 유량센서 펄스를 지멘스 PLC(S7-1200 I0.3, HSC2)로 계측하고 전자밸브 릴레이와 연동할 때 서로 다른 SMPS 사용으로 인한 기준 전위차 문제 및 HMI·SCADA·Node-RED 간 정수/실수 배율 중복 적용 오류 발생

해결: 서로 다른 SMPS의 -(0V/GND) 단자를 전선으로 묶어 공통 GND 기준을 확보하고 릴레이 5번 단자 코일 점퍼를 구성함. 또한 PLC 정수 주소(D20÷100, D22÷1000, D26÷1000)와 지멘스 실수 태그(DB1.DBD12)의 배율 적용 규칙을 통일하여 HMI·X-SCADA·Node-RED·MySQL 간 데이터 오차를 제거

🔧 트러블슈팅 3 : 물탱크 정량 주입 오버슈트 방지(D48 ≥ D38) 및 설정값 범위 제한(DLIMIT)

문제: 목표 유량(D38) 도달 판정을 단순 일치(=)로 비교하거나 작업자가 허용 범위를 벗어난 목표값을 입력할 경우, 밸브 응답 지연으로 목표치를 넘겨 계속 주입되는 오버슈트 위험 존재

해결: DLIMIT K1 K100000 D38 D38 명령으로 입력 범위를 0.001~100.000L로 안전하게 제한하고, 비교 조건을 이상(D48 ≥ D38) 및 만수위(D48 ≥ 100000, M7)로 설계하여 목표량 도달 즉시 RST M2로 전자밸브(Y10)가 차단되도록 구현

(* [ASRS] 스텝 기동 인터록 및 QD77MS4 위치결정 실행 / M코드 공압 완료 확인 *) | M42(기동요청) Y41(서보ON) M30(원점완료) X4C(1축BUSY) | |-------| |------------| |------------| |------------|/|-------------------[SET M140 (기동플래그)]--| | | | M140 | |-------| |------------------------------------------------------------[ZP.PSTRT1 U4 K1 D40 M141]--| | | | (* M코드 10: 로드리스 우이동(Y10) 및 듀얼로드 전진(Y11) → 오토스위치 CS2(X01)·CS4(X03) 완료 확인 *) | | [D12 == K10 (M코드10)] [SET Y10] [SET Y11] | | [D12 == K10] X01(CS2 우측끝) X03(CS4 전진끝) [TO U4 G1502 K1 K1] | |-------| |--------------------| |------------------| |--------------------(M코드 OFF 완료신호)----|

핵심 설계 의도: 서보 축이 이동 중일 때(X4C ON) 중복 시동을 막고, 목표 Bay 도착 후 발생하는 M코드(10·20·30·40·60·70)마다 실린더 리드 스위치(X00~X03)의 기계적 도달을 확인한 뒤에만 M코드 OFF 신호를 인가하여 포크가 창고에 걸린 채 서보가 움직이는 사고를 원천 차단했습니다.

(* [ASRS] 바코드 스캔 데이터(D732)와 목표 번호(D140) 비교 인터록 및 시그널타워(Y15~Y17) 제어 *) | M200(판독트리거) [ <> D732(스캔ID) D140(목표Bay) ] | |-------| |------------------|--------------------------|------------------[SET M902 (불일치에러)]--| | | | M902(바코드불일치) M402(입고리셋) M800(출고리셋) | |-------| |----------------|/|--------------|/|----------------------------(Y16 황색경고등/인터록)--| | | | [D20 == K104] OR [D22 == K105] (강제/축에러) SM412(1초클록) | |-------| |------------------------------------------| |-------------------(Y15 적색점멸 & 부저)---| | | | M901(종합에러판정) | |-------|/|----------------------------------------------------------------(Y17 녹색정상표시등)----|

핵심 설계 의도: 입고·출고 전 구간에서 바코드 불일치(<>) 발생 시 자기유지 셋(SET)으로 크레인 동작을 즉시 잠그고, 현장 작업자가 직접 리셋(M402/M800)을 눌러야만 해제되도록 설계하여 오입출고를 방지했습니다.

(* [IoT] 아날로그 4채널 공통 함수 블록 (FB: AD_Conv) - 0~4000 원시값 스케일링 및 단선 감지 *) | SM400(상시ON) | |-------| |---+---[FLT 현재값_AI(D0~D3) 현재값_실수 ] | | +---[FLT 스케일_정수(D30~D33) 스케일_실수 ] | | +---[E* 현재값_실수 E100 현재값_x100 ] | | +---[E/ 현재값_x100 E4000 실수_PV(D80~D86)] | | +---[E* 실수_PV 스케일_실수 HMI_실수_PV ] | | +---[INT HMI_실수_PV HMI_정수_PV(D20~D26) ] | | | | SM400 [ >= HMI_정수_PV HMI_설정값_SV(D21~D27) ] | |-------| |----------------------------------------------------------------(임계값_초과 M10~M16)---| | | | SM400 [ < 현재값_AI K-50 ] | |-------| |----------------------------------------------------------------(센서고장_단선 M11~M17)-|

핵심 설계 의도: 온도·압력·유속·전류 4개 채널의 스케일링 연산을 AD_Conv 함수 블록(FB)으로 모듈화하여 코드 재사용성을 높였으며, < K-50 비교를 통해 4~20mA 배선 단선 시 즉시 센서 고장 비트를 출력하도록 구현했습니다.

(* [IoT] 물탱크 정량 주입(D48 >= D38) 자동 차단 및 1초 하강에지(SM412) 적산 전력량 연산 *) | SM402(초기1스캔) | |-------| |---+---[DMOV K50000 D38(목표유량 50.000L) ] | | SM400 +---[DLIMIT K1 K100000 D38 D38 ] (* 설정 범위 0.001~100.000L 제한 *) | | | | [D>= D48(누적유량) D38(목표유량)] OR [D>= D48 K100000(만수위 M7)] | |-------| |----------------------------------------------------------------[RST M2 (밸브운전해제)]-| | | | M4(초기화) SM412(1초클록 하강에지) | |-----|/|---------|↓|---+---[E/ D60(전력W: 224.5*I*0.95) E3600 D64(1초분 Wh) ] | | +---[E+ D66(Wh x10) D68 D68(적산누적) ] | | +---[DINT D68 D70(HMI 적산전력량 Wh)] |

핵심 설계 의도: 매 스캔마다 전력량이 중복 가산되는 오류를 막기 위해 SM412(1초 클록) 하강 에지(|↓|) 접점에서만 P ÷ 3600을 누적(E+)하도록 설계했으며, 환산된 6대 센서 데이터는 5초 주기로 MySQL iot_sensor 테이블에 적재됩니다.
