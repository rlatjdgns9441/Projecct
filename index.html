주요 프로젝트 1 : 서보 기반 자동창고 입출고 시스템 (ASRS)

XY 2축 서보 직선보간 제어 및 바코드·공압 연동 입출고

MELSEC Q03UDV · QD77MS4 · MR-J4W2-22B · LS HMI
🎥 ASRS 자동창고 입출고 구동 및 에러 알람 시연 영상
  • 담당 역할: XY 직선보간 좌표 티칭·백업, 창고 8-Bay 입출고 동작 및 서보·공압 포크(M코드) 연동 제어
  • 강제 에러 주입 검증: 래더 및 HMI(D20·D22)에서 강제로 에러 값을 주입하여 시그널타워(적·황·녹 패트라이트) 및 부저 알람 동작 완벽 검증

🔧 트러블슈팅 1 : 미등록 바코드 잔류로 인한 오입고 방지

문제: 미등록 바코드 스캔 시 PLC 내부에 이전 정상 제품의 바코드 정보가 갱신되지 않고 남아 이전 제품 위치로 오입고되는 현상 발생
해결: 등록 제품 검색 접점(M241~M248) 전체 불일치 시 미등록 판정 플래그(M305) 및 에러 코드(K11)를 출력하고 입고 기동을 차단하는 인터락 추가

🔧 트러블슈팅 2 : 출고 바코드 에러 시 서보 무한 정지 개선

문제: 출고 스캔 실패("ERROR") 또는 품목 불일치 시 서보가 즉시 정지하여 PLC 리셋 전까지 연속 작업이 마비되는 문제
해결: 서보를 멈추지 않고 HMI 알람 팝업(M320/M321) 후 재스캔 대기 상태로 전환하며, 오출고 시 이전 출구로 자동 복귀 후 재이동하는 복구 로직 구현

🔧 트러블슈팅 3 : 공압 복구 시 예기치 않은 작업 자동 재개 방지

문제: 압력 저하 후 수동 밸브 개방 및 공압 복구 버튼 입력 시 중단된 작업이 즉시 자동 재개되어 작업자 안전사고 위험 발생
해결: 설비 상태를 '대기'와 '작업 중'으로 분리하여, 작업 중 복구 시에는 작업자가 HMI에서 중단 상태를 확인한 후 개별 재개 버튼을 눌러야만 재가동되도록 안전 인터락 강화

주요 프로젝트 2 : IoT 기반 필드 센서 계측 및 제어 시스템

다중 센서(온도·압력·유속·유량·전류) 수집·래더화 및 SCADA/DB 통합

MELSEC(Q64AD) · Siemens(S7-1200) · X-SCADA · MySQL · Node-RED
  • 다중 신호 계측 및 공학 단위 환산: 4~20mA/전압 아날로그 입력(Q64AD)과 터빈 유량 펄스 입력(S7-1200 고속카운터 HSC)을 공학 단위로 스케일링하고 임계값 초과 및 센서 고장 판별 래더 구현
  • HMI 물탱크 정량 주입 제어: 유량·압력 데이터를 연동하여 목표 유량(SV) 도달 시(D48 ≥ D38) 솔레노이드 밸브(Y10)를 자동 차단하는 응용 제어 구현
  • 상위 모니터링 및 DB 이력 관리: LS HMI, X-SCADA, Node-RED 대시보드로 실시간 트렌드를 시각화하고 5초 주기로 MySQL(iot_sensor 테이블)에 자동 저장·조회 구현
